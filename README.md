# Biblioteca Carena - Django

Proyecto de ejemplo utilizado en la asignatura Programación III.

## Funcionalidades

- ABM de autores
- ABM de libros
- Relaciones entre modelos
- Formularios HTML
- Vistas Django
- ORM
- Bootstrap

## Requisitos

- Python 3.x
- Django 4.2

## Instalación

```bash
git clone URL_DEL_REPOSITORIO
cd biblioteca
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
